# ⚔️ DUNGEON ACTION 🤠

Node.js（`rot-js`）で自動生成されたダンジョンを探索する、ブラウザ型リアルタイム・ダンジョンアクションゲームです。
限られたHPの中で押し寄せるモンスターを倒し、地下5階にある階段から地上への脱出を目指します。

## 🚀 特徴（ゲームシステム）

* **ローグライクな自動生成ダンジョン**: 階層を移動するたびに、部屋と通路がランダムに再構築されます。
* **3種類のユニークなエネミー**:
    * 🟢 **スライム**: 移動速度が非常に早いが、HPが1。
    * 👺 **ゴブリン**: 平均的なステータスを持つ標準的な敵。
    * 🤖 **固定砲台**: 移動しないが、直線上にプレイヤーを捉えると壁を貫通しない高威力レーザーを放つ。
* **リアルタイムバトルシステム**: プレイヤーが向いている方向の1マス先へ攻撃（スペースキー）を繰り出すアクション性。
* **リソース管理**: マップ上に配置されたポーション（🧪）を拾い、HPを回復しながら進む戦略性。
* **選べる3つの難易度**: EASY / NORMAL / HARD をタイトル画面で選択可能。プレイヤーの初期HP、敵の出現数、敵の移動速度が大きく変化します。

## 🛠️ 必要環境

* [Node.js](https://nodejs.org/) (v16以上推奨)
* Webブラウザ（Google Chrome, Microsoft Edge など）

## 📦 セットアップと起動方法

1.  **依存パッケージのインストール**
    プロジェクトのルートディレクトリで以下のコマンドを実行し、必要なライブラリをインストールします。
    ```bash
    npm install express rot-js
    ```

2.  **サーバーの起動**
    以下のコマンドでローカルサーバーを立ち上げます。
    ```bash
    node server.js
    ```

3.  **ゲームのプレイ**
    サーバーが起動したら、ブラウザを開いて以下のURLにアクセスしてください。
    > **http://localhost:3000**

## 🎮 操作方法

### 📋 タイトル画面 / 結果画面
* `[1]` キー: **EASY モード**でスタート
* `[2]` キー: **NORMAL モード**でスタート
* `[3]` キー: **HARD モード**でスタート
* `[Space]` キー: （ゲームオーバー/クリア時）タイトル画面に戻る

### 🤠 ゲームプレイ中
* `W` / `A` / `S` / `D` または **矢印キー（↑ ← ↓ →）**: 移動 / プレイヤーの向き変更
* `[Space]` キー: **攻撃**（向いている1マス先へ攻撃エフェクトを発生）

## 🧱 マップアイコン解説

* 🤠 : プレイヤー（あなた）
* 🪜 : 階段（次の階層へ進む。地下5階でクリア）
* 🧪 : ポーション（HPが30回復。最大値は難易度依存）
* 🟢 : スライム（高速移動・低HP）
* 👺 : ゴブリン（標準）
* 🤖 : 固定砲台（不動・直線レーザー攻撃）
* 🧱 : 壁（通行不能 / レーザーを遮る）
